# 数据来源与工具分工

公开版介绍的是 HKSC 实际使用过的数据来源。来源覆盖不等于公开版已内置所有接口，也不等于每个模块在每次运行中都会调用三个来源。

## 恒生聚源数据地图 MCP

用于定向查询公告、财务、研报、行业与结构化事实。原项目也进行过港股行情以及 A/H、ADR 跨市场查询。查询结果应保留来源、发布日期、获取时间和原文引用；跨市场比较还需要汇率、交易日和证券转换比例。

它在本项目主要承担背景资料和事实核验。HK-M1 的六项信号只使用行情，财务和公告结果不改变该规则。遇到不符合查询日期、错标的或空结果时，保留缺口，并核验官方原文。

## 腾讯自选股 WeStock MCP

用于日线历史行情、前复权价格、成交额和成交量，以及报价、分时等查询和抽样核验。原 HK-M1 盘后流程使用过 WeStock 日线快照。

前复权价格会随着公司行动重述历史。同一标的的旧快照和新快照需检查共同历史，不得直接拼接。公开版续接遇到已记录历史价格变化时停止，要求单独复核。原始数据单位需要确认后映射为 HKD 和股数。

## Futu Skills / OpenD

Skills 是访问工具；数据来源为 Futu OpenD。原项目使用过证券基础信息、快照、K 线、开盘价、盘口、点差、每手股数、板块，以及卖空和经纪商字段等只读能力。

开盘证据使用来源明确提供的 `open_price`。现价、首笔分时或机器获取时间不能代替官方开盘价和来源时间。经纪席位数据是辅助证据，不等同于完整南向净买入。SDK、OpenD、行情权限与所需字段应由使用者验证。

## 公开版接入方式

1. 在自己的 Agent 环境中配置 MCP 或只读 Skills，按工具实际文档确认能力。
2. 从 `config/providers.example.json` 建立 `local/providers.json`，填写实际工具名称和连接参数。
3. 显式选择本次主来源、标的、时间范围和复权口径，保存原始响应。
4. 按输入合同规范化字段，并将原始响应与标准化文件同时纳入哈希清单。
5. 执行输入验证，再运行研究；结果要求人工复核。

配置示例不是连接器实现。公开版通过文件接口消费外部工具结果，无隐藏请求、自动回退或后台采集。真实接入需要使用者完成 MCP / Skills 调用和字段映射。

## 必须区分的字段

| 字段 | 含义 |
|---|---|
| provider | 金融事实的数据来源 |
| access_tool | 实际调用的工具或 Skill |
| source_timestamp | 来源提供的数据时间 |
| retrieved_at | 工具获取响应的时间 |
| adjustment | 原始或复权口径 |
| amount_unit / volume_unit | 成交额和成交量单位 |
| evidence_reference | 原始响应、公告或其他证据引用 |

精确南向净买入、完整市场覆盖、所有公司行动和所有公告时点均不因某来源在架构中存在而自动得到保证。
