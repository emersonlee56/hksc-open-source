# Agent 与确定性计算的协作

本项目可以在支持 MCP / Skills 的 Agent 环境中使用。公开仓库不绑定特定 Agent 产品，也不携带第三方工具安装包。

## 来源获取任务示例

```text
为指定港股研究池获取截至指定完成交易日的研究输入。
先确认已配置工具与数据权限；仅使用只读行情和金融事实接口。

WeStock：按获授权范围获取前复权日线和基准，保存实际原始响应。
Futu Skills：按任务取得证券信息或明确的官方开盘价证据。
聚源数据地图 MCP：对指定标的定向查询公告、财务或研究背景，保留引用和发布时间。

各来源分开记录 provider、access_tool、source_timestamp、retrieved_at、单位和复权口径。
不使用账户、资金、持仓、订单或交易登录状态接口。
按 docs/input_contract.md 形成 local/ 下的规范化包和输入哈希。
缺字段、错日期或权限不足时报告缺口，不补零、不推断、不静默替换来源。
```

来源确认和字段映射完成后，用 CLI 验证输入。计算结果由规则产生，Agent 可以引用并解释，但不得改写数值或把研究状态当成真实交易事实。

## 日常研究

1. 显式选定研究日期、池成员、来源和数据口径。
2. 获取并保存原始证据，规范化后验证输入。
3. 调用 `hksc run`，需要续接时显式传入上一份公开版结果。
4. 读取 JSON、HTML 和 Markdown，检查候选变化与数据缺口。
5. 人工复核；后续研究使用新快照、新输出目录和独立版本。

定时运行是部署方的额外能力，本公开版没有后台定时器或生产自动化。任何 Agent 获取任务文本都不能替代提供方权限或用户授权。
