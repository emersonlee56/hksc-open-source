# HKSC 0.2 交付范围

| 模块 | 交付 |
| --- | --- |
| 数据 | 标准包、来源与质量检查、可选背景降级 |
| 主线 | HK-M1、候选模拟跟踪、每日行动计划 |
| 跨日状态 | 必需产物、候选与事件合同、完整股票和基准历史绑定 |
| 效果观察 | 候选毛结果、显式成本与资金假设下的组合模型 |
| 市场环境 | 只读基准与研究池广度 |
| 期间复盘 | 覆盖披露、事件汇总、绑定的效果与环境、问题延续 |
| 本地入口 | 日常运行、独立模块、完整演示和交付检查 |

闭环是合成数据与明确研究假设下的本地实现，不是生产交易系统验收。

## 兼容性

输入仍采用 `hksc-public-bundle/1`。运行为 `hksc-public-run/2`，历史绑定为 `hksc-history-bindings/2`，包含股票和基准的 OHLC、成交额、成交量及之前的缺失状态。

原型运行不自动迁移或续接，旧产物不修改。使用新目录建立起点。策略保持 `hkm1_public_research_v0.1`，未改变经济规则。

## 未包含

- 原生供应商连接器和真实数据下载，目前仍为外部工具加文件桥接。
- 真实来源可用性、权限与字段映射验收。
- 真实前向证据、策略盈利或完整交易业绩。
- 生产定时器、后台采集、跨机器恢复和自动部署。
- 多策略、自动调参、真实账户或订单操作。
- 完整真实交易成本、公司行动与结算模型。

## 验收

合成测试、故障注入、隔离本地命令链和独立 agent 审查分别记录，不扩大为真实来源或调度结论。详情见 [验收记录](acceptance.md)。
