# 公开发布范围

从原项目只选择扫描、质量检查、核心池读取和模拟生命周期四个代码模块。公开改动包括可移植路径、用户清单绑定的池成员、公开研究版本和通用人工复核标记。模块来源哈希记录于 `export_manifest.json`，便于追溯代码抽取范围。

公开版独立 Git 历史，不含原项目提交、远端配置、生产合同绑定、真实池、历史成交、运行收益、任务实例、审计事故、机器路径、个人记忆、凭据或账户数据。示例数据由程序生成，不重写真实行情冒充合成数据。

许可证为 MIT，数据与工具遵循各自授权。真实连接配置和数据保存在 `local/`；运行产物保存在 `outputs/`，均不进入版本控制。

发布检查使用显式文件清单。测试只覆盖合成数据行为和故障输入，不能描述成真实来源接入、WB 独立 QA、真实调度或生产验收通过。
