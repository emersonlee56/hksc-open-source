# HKSC 评价口径

## 评价层级

| 层级 | 处理 |
| --- | --- |
| 候选 | 根据模拟事件计算，未结束候选单独标记 |
| 组合研究模型 | 仅在提供显式资金与成本政策后重放事件 |
| 真实交易与 Alpha | 当前不提供，不从演示推断 |

评价绑定研究产物、原输入包、策略版本和研究池。日历、成员绑定与来源记录必须一致。

## 候选结果

已结束候选毛收益为 `exit_price / entry_price - 1`。R 倍数为价格变化除以进入价与初始止损的差值。

`CLOSED`、`OPEN`、`NOT_ENTERED` 与 `INCOMPLETE` 分开统计。缺进入证据或持有期数据归为不完整；未结束候选按研究日收盘标记，不计入已实现结果。

基准参考为进入日开盘到退出或观察日收盘，不能还原盘中触发时刻的同步基准，因此不称为精确执行收益比较。

## 成本政策

政策明确格式、假设名称、初始假设资金、每候选使用初始资金的比例、单边佣金和滑点 bps。只影响评价，不改变策略事件。

设单边佣金率为 `f`、滑点率为 `s`，已结束候选模型净收益为：

```text
exit * (1 - s) * (1 - f) / (entry * (1 + s) * (1 + f)) - 1
```

未提供政策时不输出净收益。明确配置零成本也只是一种假设，不代表真实交易没有费用。

## 组合模型

- 每次进入使用固定初始资金比例，费用计入预算。
- 允许分数股，不处理真实整手、分红或税费。
- 不借款、不超过可用现金、不改变三开放候选容量。
- 开盘退出、开盘进入、盘中退出依次处理，盘中资金不能提前用于开盘。
- 持有对象按收盘标记，不扣未来清算费用。
- 毛模型与成本后模型分别计算日线资金曲线、区间收益和最大回撤。
- 基准曲线是同起点的无成本日线参考。

固定预算超出现金时标记 `ASSUMPTION_BLOCKED`，不偷偷减预算或跳过策略事件。缺行情时标记 `DATA_BLOCKED`，不补零；有效候选级结果可以保留。

## 限制

不覆盖完整券商费用、容量、市场冲击、整手交易、现金收益或公司行动结算。前复权历史不能当作实际现金记录。

不年化短演示收益，不以少量样本证明有效性，不将候选均值当作组合收益。研究池选择可能有幸存者偏差。
