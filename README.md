# HKSC · 港股 AI 研究工作台

从数据获取、规则扫描，到候选生命周期和每日研究报告。

HKSC 是一个面向个人研究者的港股研究项目。本公开版从实际使用的 HKSC 中抽取确定性扫描、数据质量检查和模拟生命周期模块，建立独立版本与 Git 历史，提供可复现的合成数据演示。

AI 工具负责获取与整理证据；Python 规则负责计算；研究者负责判断。代码和示例可以开源，外部数据服务由使用者自行授权接入。

## 三类数据来源

以下是原研究项目实际使用过的来源与分工，覆盖情况取决于接口、权限与具体任务。

| 来源与访问方式 | 在研究流程中覆盖什么 | 使用边界 |
|---|---|---|
| 恒生聚源数据地图 MCP（GilData） | 公告、财务、研报、行业信息与结构化事实的定向检索；个别行情及 A/H、ADR 跨市场核验 | 补充事实与研究背景；公告日期和原文需核对，不参与 HK-M1 行情信号计算 |
| 腾讯自选股 WeStock MCP | 历史日线、前复权价格、成交量与成交额；报价、分时及交叉核验 | HK-M1 盘后研究的数据输入之一；复权口径、单位和日期必须显式记录 |
| Futu Skills / OpenD | 证券基础信息、行情快照、K 线、官方开盘价字段、盘口、点差、每手股数；板块、卖空与经纪商等辅助字段 | 仅使用获授权的只读行情能力；Skills 是访问工具，数据来源记录为 Futu OpenD |

三者按场景互补，不默认自动切换或合并口径。港交所和披露易原始资料用于交易日、证券身份和公告时间的最终核验。

本公开版内置的是外部数据结果的规范化输入与验证流程。第三方 MCP、Futu Skills 和服务凭据不随仓库发布；需要在使用者自己的 Agent 环境中配置。离线演示不调用这些服务，也不证明它们当前可用。

## 快速体验

Python 3.10+，离线演示无需安装第三方运行依赖。

```bash
python -m hksc demo
```

打开 `outputs/demo/followup/report.html`，或阅读同目录 `report.md`。演示会生成 140 个虚构标的、两个日期的数据快照、规则扫描、模拟候选续接、事件和文件哈希。

所有价格、日期、标的和结果均为合成演示。基准代码只用于匹配引擎接口，其价格同样虚构。

需要命令行安装时：

```bash
python -m pip install -e .
hksc demo --output outputs/my-demo
```

## 可以做什么

- 用六项确定性规则扫描中期动量与价格突破，并保留未入选原因。
- 检查历史覆盖、重复日期、未来行、OHLC、复权声明和数据单位。
- 跟踪最多三个模拟候选，演示追价限制、止损、目标、趋势和时间退出。
- 续接上一份公开版研究结果，核验旧产物哈希与历史价格一致性。
- 生成 HTML / Markdown 阅读报告，以及可复核的 JSON 结果和输入哈希。
- 将三类来源组织成有日期、口径和证据引用的外部输入。

公开版没有完整组合回测和净收益评价；生命周期结果不包含费用、滑点、股息或市场冲击。它是研究流程示例，不代表策略已经产生 Alpha。

## 接入自己的数据

将获授权工具的结果规范化成输入包，保存在忽略目录 `local/`。

```bash
python -m hksc validate-input --input local/snapshot
python -m hksc run --input local/snapshot --output outputs/research-001
python -m hksc run --input local/next-snapshot --prior outputs/research-001 --output outputs/research-002
```

输入格式、来源配置和 Agent 工作流见 [数据来源](docs/data_sources.md)、[输入合同](docs/input_contract.md) 和 [协作流程](docs/agent_workflow.md)。示例规则见 [HK-M1](docs/strategy.md)。

## 项目结构

```text
hksc/                 公开版入口、输入校验、合成数据、报告和续接
hksc_engine/          从 HKSC 抽取的扫描、质量与模拟生命周期核心
config/               外部来源配置示例，无凭据
docs/                 数据覆盖、输入合同、规则与发布范围
tests/                合成数据单元与故障注入测试
scripts/              公开发布文件检查
```

## 开源边界

本仓库不包含原项目 Git 历史、真实行情包、个人股票池、运行账本、账户信息、任务实例、自动化配置或凭据。演示和外部数据结果分别存放在忽略的 `outputs/` 与 `local/` 中。

代码采用 MIT 许可证；外部服务和数据的使用权遵循对应提供方授权。来源名称表示实际使用关系，不表示官方联合产品或厂商背书。所有功能仅用于研究与模拟，不访问账户或执行订单。
